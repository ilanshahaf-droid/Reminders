# תזכורות
1. צור repo ב-GitHub, העלה את כל הקבצים (כולל התיקייה .github), ענף main.
2. לשונית Actions ← Build APK ← כשהסתיים, הורד את reminders-apk מה-Artifacts.
3. חלץ את ה-ZIP, העבר את app-debug.apk לטלפון והתקן (אפשר התקנה ממקורות לא ידועים).
4. פתח את האפליקציה ← הגדרות ← אשר התראות וסוללה ללא הגבלה.
